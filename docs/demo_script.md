# 3 分钟演示脚本

> 目标：让评委在 3 分钟内看到「这不是套壳 RAG」——稀有度是算出来的、亲缘是查出来的、检索是一条 SQL。

## 准备

```bash
LLM_MODEL=/workspace/models/qwen2.5-7b-instruct bash scripts/start.sh
```

浏览器开 `http://<ip>:8077`，提前把「合成台」「检索」「生态」三个页签点一遍预热。

## 0:00–0:20 开场

> 「别的应用是拿 AI 聊天，这个应用是拿 AI 造物。你给它两个八竿子打不着的词，它在 512 维空间里让这两个词交配，生出一只新物种，写进 OceanBase seekdb。」

## 0:20–1:00 造一只

输入 `冰箱 × 蝴蝶`，点「合成新物种」。

边等边说：
> 「它现在在做三件事：把两个词 embedding 成 512 维向量；按 50:50 混合并加一点可复现的突变；拿这个基因组去 seekdb 里做一次 HNSW 最近邻，看园里谁跟它最像。」

出卡片后指着说：
> 「稀有度不是 LLM 编的，是刚才那次 KNN 的距离在全园的分位——**越不像别人，越稀有**。」

## 1:00–1:40 检索

切到「检索」，输入「冷气」，点检索，展开下面的 SQL。

> 「seekdb 一条 SQL 同时算两件事：`COSINE_DISTANCE` 的语义相似度，和 ngram 全文索引的关键词得分，再叠加 JSON 元数据过滤。换成传统方案，这里是三个组件、三份数据、三次网络往返。」

## 1:40–2:20 去重（最能说明"库在干活"）

回到合成台，同样的词再点一次。

> 「它说这个组合已经诞生过了——因为基因组是确定性的，seekdb 在 0.03 距离内直接找到了旧物种。这不是缓存，是向量检索。」

## 2:20–3:00 收尾

切到「生态」：物种数、稀有度分布、基因多样性。

> 「基因多样性是两两余弦距离的均值，也是数据库里算的。整套东西就一个 seekdb：向量、全文、JSON、统计，一个库顶三个组件；上面是 Dify 的 9 个节点在编排。谢谢。」

## 如果现场翻车

| 情况 | 兜底 |
| --- | --- |
| 模型加载慢 | 提前预热；或先放 `docs/evidence.md` 的截图 |
| 生成质量差 | 换 qwen-plus（`LLM_BACKEND=openai`），文风立刻正常 |
| 网络不通 | 全部本地：模型、seekdb、前端都在一台机器上 |

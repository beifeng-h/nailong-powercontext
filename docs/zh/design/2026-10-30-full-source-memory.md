# 完整来源正文与 Memory 写入长度

PDF 题要求完整物理页作为标准文本证据进入真实 Memory。固定采集流程为每个 Source 生成一条正文为完整投影的记忆；页面不能为适应存储限制而截断、改成摘要或移动到其他页面。

普通记忆的 8192 UTF-8 字节写入上限与全文来源是两项不同约束。原实现把这个上限同时用于候选写入、内容哈希和既存版本回读，导致合法长页虽然完成 PDF 解析和 Source 采集，仍无法成为 Memory 条目。Source 日志数量正确不能证明完整正文已入库。

## 写入准入

普通手写、生成和修改候选继续经过原有 NFC、非空和 8192 UTF-8 字节校验。

只有候选超过该上限时，才检查它是否为完整来源正文。来源必须已通过 Source resolver 和本次操作的允许集合核对，状态为 CAPTURED；其标准 text-evidence 投影的来源类型和 ID 必须对应同一来源，且完整投影正文与候选按原有 NFC、去首尾空白规范化后相等。符合全部条件才允许保存全文。

规则不依赖 pdf-page 名称、公司、题目或页码。仅附加来源、改写来源内容、使用操作范围外的来源，均不能放宽普通候选的限制。手动修改既存长条目也不能仅因旧版本有来源而自动获得例外；校验使用本次候选实际提供且获准的来源。

## 编码、完整性和门禁

canonical 内容编码只负责完整内容的规范化与哈希，不重新执行新候选的写入准入。8192 字节以内的旧内容使用相同规范化、JSON 结构和哈希域，既有身份不变。持久化重建会对完整长正文重新计算同一内容哈希。

写入门禁使用截断的临时证据预览，预览的规范化不应先触发持久正文的 8192 字节限制。原有预览长度预算、完整性标记和门禁决定仍然适用。

HTTP 手写 Remember 与 Revise 没有完整来源候选，因此继续服从普通写入上限；接口形状和生成 API 文件不变。SQLite Text 与 MySQL MEDIUMTEXT 已支持所需正文，无新增存储 schema。

## 验收边界

- 使用页面可视范围内排版的合法长页、空白页和短页，解析后逐页核对 Memory 条目数，重开数据库回查完整正文、摘要和物理页码。
- 用尾部词项做真实全文检索，核对精确引用；执行索引重建并再次回查，防止只修写入而回读仍受限。
- 验证 UTF-8 字节边界，普通条目 8192 字节通过、8193 字节失败。
- 验证来源正文不相等、来源未获本次操作授权、来源未实际采集的长候选仍失败。
- 重跑原有 canonical、Memory 服务、持久化和写入门禁回归，以及受共享 Memory 改动影响的全部公开赛题。

此前 755 页人工诊断原件的完整投影最大为 7309 字节，未覆盖此边界。公开辅助流程只核对 Source journal 数量且不要求相关检索非空，不能代替逐页 Memory 入库验收。正式提交 9391cff1f1ca54ad7bfbed5fc44be878df085247 的第四题仍为 0 分，未披露失败维度；长页链路的已确认代码缺陷不等于已证明正式唯一根因。

## 实际验证

2026-10-30，在 Python 3.12.3、官方固定 78 项依赖环境完成真实 Runtime 对照。2144 字节控制页在旧新实现均完整持久化；10664 字节长页在旧实现触发 8192 字节限制，在修复实现完成 Source 采集、Memory 入库、关闭重开、全文精确回读与检索。

旧实现运行新增容量测试精确失败两个长正文正例，其他四项控制通过；修复实现六项全部通过。`tests/test_pdf_parsing.py`、`tests/test_pdf_page_search.py`、`tests/test_pdf_page_capacity.py` 合计 81 项通过；十道公开代码题合计 95 项通过，无失败、错误或跳过。

四份原件的 755 个物理页逐页核对 Source 与 Memory 一一对应，并验证完整正文及引用。16 道人工开发诊断题的 23 个支持页全部保留；这些题已参与开发，不能称为盲测或官方质量评测。

七份 canonical、Memory 服务、持久化和 HTTP 写入门禁核心测试在复制的隔离开发环境中重跑，80 项通过，13 项因未提供一次性 `POWERCONTEXT_TEST_OCEANBASE_URL` 按条件跳过。开发补充仅安装仓库锁定的 server 依赖；官方固定环境元数据与 RECORD 摘要前后不变。原固定环境中因缺少 server 开发依赖产生的 collection error 保留在原日志和原汇总中，由独立补充结果完成验收，不改写原失败记录。

验收包的 543 个文件前后 SHA256 一致；本地 440 个源码与测试文件与被测包字节一致。未执行全库 lint/type、多 Python 版本、独立 OceanBase 数据库或完整官方 Docker 隔离验收；正式隐藏评分仍需平台提交验证。

# 财报复合问题的报表覆盖

财务问题可能明确要求同时使用利润表和现金流量表。仅把问题词项与通用财务扩展词加总，会让讨论这些概念的管理层分析页面排在真正报表前面。相同公司内的词项竞争也会发生，按公司过滤不能解决。

`search_pdf_pages` 保留现有公司范围、BM25、公开 Memory 全文信号和多样性排序。问题明确提及 income statement、statement of earnings/operations、cash flow statement、balance sheet 或相应常见表达时，另外建立这些报表类型的覆盖要求。共享 statement 修饰的并列说法（例如 income and cash-flow statements）分别展开为对应来源。

问题明确要求比例、百分比、加减或其他财务算术时，还根据实际出现的财务科目推导来源：销售收入、经营利润等对应利润表；经营现金、资产购置和折旧摊销等对应现金流；流动或总资产负债、权益等对应资产负债表。隐式覆盖必须同时识别至少两种不同报表来源；单一科目的比例继续普通排序。例如地区收入占比、诉讼付款占收入比例不会仅因出现 revenue 而强制返回利润表。显式或共享并列的报表要求保持原样，无关问题仍为空。

候选必须在正文开头的独立标题行匹配对应报表类型；支持常见 consolidated/condensed 等修饰、单复数、Profit and Loss/P&L、Cash-Flow 等同义标题、最多三行换行标题及 continued/unaudited 标记。句子中提及报表、目录行附带页码或其他说明不会仅凭关键词成为报表候选。识别只使用已存原文，没有固定公司、问题或页码。

每种覆盖要求按原有分数取最多两页，先轮流保留每种类型一页，再补充第二页，以容纳续表。余下名额交给原有普通选择。所有条目来自当前 scope 的真实 Memory 引用，按 Source 身份去重，最终仍服从调用方 limit；名额不足时按问题中首次提及报表或对应科目的顺序分配。

补充回归在真实 Runtime 中持久化并重开一份 53 页合成报告：两页真正报表、21 页重复财务关键词的讨论、30 页普通财务背景。原排序的 Top20 全为讨论页；修复后的显式双报表问题必须返回两页真实引用，并检查返回上限。另覆盖换行及续表标题、资产负债表与现金流的联合要求。既有公司、scope、无关问题与引用测试继续保留。

该对照验证已复现的复合问题覆盖缺陷。没有读取 FinanceBench 答案、证据或标注页，公开 PDF 的独立原文检查也不等同正式 evidence-page Recall；正式质量仍由平台核验。

## 固定环境验证

2026-10-30，固定 pypdf 6.19.0 与独立 pdfplumber 对同一公开 PDF 的全部 503 页进行了词频比较。所有页的词数比例均在 90%–110% 内，所有页的词频 F1 均不低于 0.95，按词数加权的 F1 约为 0.99992。pdfplumber 只是独立解析器，不是比赛标注；该结果支持保留原文本提取方式，不能替代正式解析质量核验。

另外从四份完整原财报人工编写并先冻结 12 道诊断问题及支持页，未读取官方答案或证据。固定 6.19.0 原文上，实际排序函数在旧实现命中 13/16 个支持页，新实现命中 16/16。另四道人工作为保留问题的命中仍为 6/7，与旧实现相同；未为追求样本满分扩充科目特例。这些是人工诊断样本，评分相关性已被用来检查和修复实现，不属于盲测或官方成绩。

真实 Runtime 行为回归包含共享并列名称、跨报表计算及地理/法律占比的误路由。固定 Python 3.12.3、pypdf 6.19.0 和全部 78 个官方固定依赖的云端环境中，旧搜索实现执行 34 项 PDF 回归时有 3 项失败，当前实现 34 项全通过。公开 PDF 6 项、CSV 17 项、Pi 15 项也全部通过，当前实现共 72 项检查通过，无错误或跳过。

四份原件的全部 755 页通过真实 Source 解析、投影和入库，并重开同一数据库。包含实际 FTS 信号的新旧搜索对照中，12 道人工诊断题的支持页命中从 13/16 提升到 16/16；另 4 道保留问题新旧均为 7/7。每条返回引用均经 Memory 回查，核对 PDF 摘要、物理页码、完整正文、去重与 limit。该结果与省略 FTS 的隔离评估分别记录，不能混为同一检查。

首次公开 Pi 检查在样例 SHA 校验处失败，原因是测试包带入 Windows CRLF。云端副本恢复后与官方 LF 原件逐字节哈希一致，15 项重跑全过；原失败日志保留，Pi 产品代码和断言均未更改。外部打包脚本已改为从 Git 对象读取官方公开资产，防止再次带入换行转换。

本次产品改动限于 PDF 检索模块，官方判题资产和其他题实现未改。完整仓库 lint、类型检查未运行；本机完成 AST 和 Git 空白检查。正式评分仍需使用已验证的新提交重新提测，不能将独立诊断结果当成完整语料 Recall 门槛已经通过。

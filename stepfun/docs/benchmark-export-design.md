# 比较报告导出

比较页在报告生成后提供“导出原始 JSON”按钮。文件内容逐字采用页面 `#raw` 已显示的完整 JSON，文件名包含本次 runId。完整和部分失败的报告均可导出，导出不重新执行比较、不发送网络请求。

采用主应用已有的 Blob 下载方式。浏览器原生另存网页仍可人工使用；自动化接口返回全文存在长度限制，不作为原始报告存储通道。

报告尚未生成、或新一轮正在运行时，导出按钮不可用。渲染报告时先保留原始 JSON，再渲染摘要表。下载状态只提示“已发起下载”，不声称文件已成功落盘。临时链接用后释放，浏览器失败不触发自动重试。

改动仅涉及比较页和它的页面控制器，不改变模型、数据、推理、检索、计时或评分。已打开的比较页不刷新；新控件在后续正常打开页面时生效。历史运行继续绑定各自实际使用的源码版本。

验证使用真实页面控制器和替代 DOM：检查报告生成前无下载；含中文且大于 200,000 字符的完整报告可无截断导出；部分失败报告可保留；临时链接得到释放。该验证不代表浏览器模型推理或原生下载已经验收。

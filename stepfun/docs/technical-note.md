# 端侧知识库：技术说明

文档与查询均由浏览器 Worker 本地向量化，Node 只提供回环 HTTP 和 seekdb 存储/检索。模型为 Apache-2.0 的 Xenova/all-MiniLM-L6-v2，固定 revision `751bff37182d3f1213fa05d7196b954e230abad9`，384 维、mean pooling、L2 归一化；使用发布的 FP32、FP16、q8 ONNX。q8 图包含 INT8/UINT8 权重及 FP32 数据，不等同全部运算均为 INT8。Transformers.js 3.8.1 和 ORT Web 资源固定版本与校验。

自动模式优先 WebGPU/FP16；不可用或初始化/推理失败时使用新的 WASM/q8 Worker，界面显示实际后端。2026-11-02 历史版本的自动回退及一文档查询记录见 [自动回退证据](../evidence/automatic-wasm-20261102/README.md)。seekdb-js 1.4.0 使用嵌入式库，collection 存向量、原文及 metadata，建立 cosine/HNSW 和全文索引；写入后刷新，参数化 SQL 在数据库内完成向量与全文 RRF 融合。不同知识库和请求按状态隔离。运行、数据及模型获取见 [README](../README.md)。

**对照实验。** 2026-11-03 14:13–14:17 UTC，Windows、Edge 156、Intel gen-12lp；独立候选源码提交 `a67ba18b886320b00b8ef13641f90f3c1cfd60b7`，20 篇 AI 辅助合成开发文档、10 个查询，每查询 3 次，另每模式 2 次预热；标注非官方 gold。相同模型资源口径下 FP16 相对 FP32 压缩 1.975 倍，q8 相对 FP32 压缩 3.819 倍。完整[原始 JSON](../evidence/browser-run-41a5bb18/BENCHMARK.json) SHA-256 `3c231656a63a56cd620c2e74926aa75f2fa67417686a5486c45321ddd97daad5`；报告不含提交号，版本绑定来自独立启动和进程记录。

2026-10-31 的独立资源获取记录中，FP32、FP16、q8 权重串行下载分别耗时 19.141、11.429、6.207 秒；计时含 HTTPS、重定向、读写和落盘，不含共享配置与运行时包，详见[脱敏摘要](../evidence/browser-run-84b3efd7/WEIGHT_DOWNLOAD_SUMMARY.json)。这不是 11 月 3 日浏览器实验的同次冷启动，不能与下述初始化耗时相加。

初始化包含缓存/文件获取和会话建立；首次为新 Worker、未清除浏览器/模型/设备缓存。文档向量化为 20 篇共享批次；后续为每题第 2、3 次中位数，ready 包含查询向量化及数据库往返。显示计时为 DOM 更新及两次动画帧机会，不是物理呈现时刻；本次显示值较高，浏览器调度及前台条件未单独校准。WASM 为显式模式，不代表本候选自动回退已复测；历史自动回退见上文证据。完整样本保留于原始记录，不能据小规模开发集推断正式得分。

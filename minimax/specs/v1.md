# Taskboard state filtering — version 1

Specification ID: TASKBOARD-STATE-FILTER. Logical source key: taskboard/state-filter. This is the active specification before the requested update.

`list_tasks(tasks, state=None)` accepts an ordered list of task mappings with string `id`, `title`, and `state`. State labels are extensible nonempty strings already in canonical form: no leading/trailing Python `str.strip` whitespace and equal to their own Python `str.casefold` value. The supplied fixture uses `open`, `done`, and the custom label `strasse`. State labels are not a closed enum.

- `state is None`: return all records in their original order.
- A string filter selects records whose stored state equals the filter exactly.
- An unmatched string returns an empty list.
- Preserve order, every record field, and the input list/mapping contents.
- An empty task list returns an empty list.

Non-string filters other than None, missing record fields, invalid state storage, Unicode NFC/NFKC transformation, sorting, and deep-copy guarantees are outside this sample contract. The caller must supply valid inputs.
